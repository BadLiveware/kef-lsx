# Teardown photographs

Photographed during disassembly of the author's own KEF LSX (gen 1) **master**
speaker on 2026-11-04. Serial `KMLSX#############`.

These document the retention scheme, which is not described in the manual and
not described in any published teardown. The critical discovery is
`09-recessed-screw-in-bore.jpg`: the black cylindrical posts on the heatsink
plate each conceal a **recessed screw** that clamps the back plate to the front
baffle.

Downscaled to 1100 px wide at JPEG quality 82 for repository size. Originals were
1848x4000.

Third party reference photos are **not** copied here. See the links in
[`../../uart-plan.md`](../../uart-plan.md) for the AudioScienceReview teardown and
the Darko.Audio LS50 Wireless internals.
